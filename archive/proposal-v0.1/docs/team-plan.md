# 三人分工与阶段计划

版本：2026-10-27，拟议分工。A 为仓库发起人；B、C 待组内认领，不推定具体成员身份或能力。

## A：研究统筹与可复现评测

负责把研究问题、文献、接口协议和评测口径收敛成可执行计划，并承担实际评测工具的开发。

- 交付 proposal、相关工作差异说明、数据清单与划分协议。
- 实现实验配置、运行清单、结果聚合、统计分析和失败案例标注；不是只做 PPT。
- 维护版本、样本 ID、种子、模型配置、成本统计与运行结果的关联。
- 复核 B 的消融设计、C 的运行与重放行为；主持每阶段范围冻结。

验收：同一组日志能重算指标；独立运行能定位具体失败任务；正文中的每个结果能追到配置和原始记录。

## B：Memory 方法与机制验证

建议由偏算法成员承担。负责 `MemoryBackend` 适配契约、Jev TierMem 封装与普通检索基线；设计和实现一种明确的改进。

- 原文与摘要关联、检索策略、显式更新关系、依赖和失效处理。
- 与 A 冻结写入 / 查询协议、开发和测试边界及人工抽查规则。
- 对关闭原文回查、关闭失效处理等条件做消融，定位收益来源。
- 仅在无训练版本的瓶颈和数据来源明确后考虑学习路由器。

验收：每个返回证据可回溯原始事件；引用存在性与语义支持分别校验；对照使用相同输入、模型和预算；报告失败与无收益情况。

## C：Smurfs 集成与后端 / AI Infra

负责可测量的执行系统，将 Agent、memory、任务环境连接为一个可追踪运行链。

- Smurfs worker 封装、模型客户端、任务 / 工具环境适配。
- 隔离每个实验条件和任务组的存储，设计串行写入、失败记录、幂等事件 ID 与恢复入口。
- 统一调用预算、超时、取消和重试；记录队列等待、服务时间、端到端时间。
- 在固定任务混合上测试并发和延迟，输出吞吐、P50/P95、失败率和成功率。
- 若具备自托管资源，再增加推理服务实验；没有硬件测量时仅报告 API 服务层结果。

验收：两个独立任务不能读到彼此记忆；超时与重复执行有明确状态；失败样本进入分母；取消与重试开销被记录。

## 共同责任

每人认领一个主要模块、审查一个其他模块，并维护自己贡献的代码、实验或分析记录。角色可调整，但最终应能分别回答问题、实现、取舍、结果与局限。三人共同阅读 Smurfs 和 TierMem 的关键部分。

## 相对阶段安排

以下周次为建议工作节奏，不是课程正式日程。具体日期由团队结合课程通知填写。

### 第 1 周：可行性与范围冻结

- A：整理引用与数据协议，给出固定开发样本清单。
- B：在本地用模拟 provider 验证记忆契约，再核对真实 Jev 服务的可用性与预算。
- C：跑通一个使用本地工具的 Smurfs 任务；验证 MemoryArena 候选环境入口。
- 共同验收：一条完整可读轨迹、最小接入成本记录、明确的主数据集和备选方案。

### 第 2 周：基础链路与基线

- C 提供有预算控制的 Smurfs runner 和事件协议。
- B 提供相同接口下的近期窗口、普通检索和 Jev 记忆。
- A 用 5-10 个开发单元验证评测器、数据隔离和成本汇总；数量可据实际成本调整。
- 验收：同一命令配置能切换记忆策略，所有方法能产出统一结果或明确失败状态。

### 第 3 周：单一机制与协议冻结

- B 实现一种受控更新下的失效处理，避免同时加入大量新机制。
- A 固定测试清单、随机性设置、指标、judge、重复次数与预算。
- C 完成所需恢复 / 超时行为并冻结对照共用的代码修复。
- 验收：阶段末停止使用测试结果调策略；新改动若依赖测试反馈，应另留最终测试集。

### 第 4 周：主要实验

- A 执行配对结果分析、人工抽查和错误类型统计。
- B 完成机制消融和检索预算实验。
- C 完成固定任务混合下的并发 / 延迟评测。
- 验收：数量、成本、失败和方差透明，原版与修改任务的结果分开。

### 第 5 周：复现与展示

- 三人交叉复现对方至少一项关键结果。
- 演示一个成功案例和一个失败 / 恢复案例，展示工具事件、原文、摘要、检索与最终行为。
- 统一贡献说明、引用和局限；套用正式课程模板。

## 最小范围与扩展范围

最小范围是一套任务、一种改进、可复现对照与消融。第二套行动任务为目标；学习路由、跨进程 MCP、真实 GPU 调度和第二个多 Agent 底座均不是首版依赖。

## GitHub 协作建议

用小分支与 PR 留下代码和设计审查；每项实验记录来源提交和配置。推荐任务标题：`memory: ...`、`runner: ...`、`eval: ...`、`docs: ...`。不要把尚未实现的 API 或预计提升写成已交付成果。
